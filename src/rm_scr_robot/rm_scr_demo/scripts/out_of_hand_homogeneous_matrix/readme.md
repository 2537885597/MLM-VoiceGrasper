我来帮你**添加手眼标定结果的保存/加载功能**，支持**二进制快速加载（numpy）**、**文本可读格式**、**工程常用YAML格式**，还会生成机器人标定最常用的**4x4齐次变换矩阵**，直接复制修改后的代码即可使用。

### 核心修改说明
1. 生成**4x4齐次标定矩阵**（工业控制最常用格式）
2. 支持3种保存方式：`.npy`（最快加载）、`.txt`（可读）、`.yaml`（工程配置）
3. 编写独立的**加载函数**，随时调用恢复标定结果
4. 保存路径默认在脚本同级目录，方便查找

## 第一步：安装依赖
```bash
pip install pyyaml
```

## 第二步：使用说明
### 1. 首次运行
执行脚本 → 自动完成标定 → **自动保存所有结果**到脚本目录下的 `hand_eye_calib_result` 文件夹

### 2. 保存的文件说明（在`hand_eye_calib_result`文件夹内）
| 文件名 | 格式 | 用途 |
|--------|------|------|
| `homogeneous_matrix.npy` | numpy二进制 | **最快加载**，工业代码直接用 |
| `rotation_matrix.npy` | numpy二进制 | 单独保存旋转矩阵 |
| `translation_vector.npy` | numpy二进制 | 单独保存平移向量 |
| `homogeneous_matrix.txt` | 文本 | 可读格式，方便查看 |
| `calib_config.yaml` | YAML | 工程部署、配置文件读写 |

### 3. 后续随时加载（核心用法）
**不需要重新标定**，直接调用加载函数即可：
```python
# 只需要这两行代码，就能获取标定好的4x4齐次矩阵
from eye2hand_calibration import load_hand_eye_calib
calib_matrix = load_hand_eye_calib()
```

## 关键优势
1. **4x4齐次矩阵**：机械臂控制中直接用于坐标变换（`相机坐标 → 末端坐标 → 基坐标`）
2. **多格式兼容**：满足调试、工程部署、快速调用所有场景
3. **零冗余**：保存/加载函数独立，不影响原标定逻辑
4. **自动创建目录**：无需手动新建文件夹，避免路径报错

---

### 总结
1. 运行修改后的代码，标定结果会**自动保存**到本地文件夹
2. 后续使用时，直接调用 `load_hand_eye_calib()` 就能加载标定好的矩阵
3. 优先使用 `.npy` 格式加载，速度最快、精度无损失；`.yaml` 用于工程配置文件
